DEPLOYMENT STEPS
1. Open the GitHub repository on the main branch.
2. Upload/replace the seven website files listed above in the repository root.
3. Make sure index.html is in the repository root, not inside another folder.
4. Commit the changes to the main branch.
5. In GitHub, open Settings > Pages and confirm deployment is configured from the main branch and /(root).
6. Open the website root URL. If the old version appears, refresh after GitHub Pages finishes deploying or clear the browser cache.
